# Муравей — Lifan KP230 (flat-base)

Исправленная версия без углублений под рельефом.

## Геометрия
- ширина: **≈159.9 мм**
- высота: **≈57.0 мм**
- общая толщина: **3.00 мм**
- полностью ровная подложка: **Z=0.00…2.00 мм**
- рельеф начинается только с **Z=2.00 мм** и поднимается ещё на **1.00 мм**
- отверстия: **Ø4.6 мм**

В подложке нет отрицательных отпечатков текста, шестерёнки, муравья, рамки или полос. Единственные сквозные вырезы — два крепёжных отверстия.

## Рекомендуемые файлы
- `muravey_lifan_kp230_flatbase_v2.stl` — основной цельный STL.
- `muravey_lifan_kp230_flatbase_layerchange_v2.3mf` — один цельный объект для Bambu Studio.

Для смены цвета **не объединяйте отдельные black/silver STL в один объект с частями**. Используйте цельный flat-base файл и добавьте смену филамента по слою на **Z=2.00 мм**. До этой высоты печатается полностью ровная чёрная подложка; выше — только серебристый рельеф.

Отдельные `black.stl` и `silver.stl` оставлены только как вспомогательные исходные части.

Для сопла 0.4 мм: слой 0.16–0.20 мм, Arachne. Для максимально жёсткой и ровной тонкой подложки можно использовать 100% заполнение.
