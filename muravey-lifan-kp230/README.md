# Муравей — Lifan KP230

Печатный двухцветный шильдик по финальному дизайну с центральной шестерёнкой и муравьём.

## Размеры
- ширина: **159.86 мм**
- высота: **57.00 мм**
- общая толщина: **3.00 мм**
- чёрная основа: **2.00 мм**
- серебристый рельеф: **1.00 мм**
- крепёжные отверстия: **Ø4.6 мм**

## Файлы
- `muravey_lifan_kp230_combined.stl` — единая модель. Для ручной смены цвета печатать чёрным до Z=2.00 мм, затем сменить на серебристый.
- `muravey_lifan_kp230_black.stl` — чёрная основа.
- `muravey_lifan_kp230_silver.stl` — серебристый верхний рельеф.
- `muravey_lifan_kp230_multicolor.3mf` — две совмещённые детали для Bambu Studio / AMS.
- `muravey_lifan_kp230.scad` — параметрический исходник OpenSCAD.
- `muravey_lifan_kp230_preview.png` — превью геометрии.

## Рекомендации для Bambu Studio
Для сопла 0.4 мм: слой 0.16–0.20 мм, генератор стенок Arachne. При открытии 3MF, если Bambu Studio спросит, загрузить ли несколько частей как единую модель, выбрать **«Да»**. Затем назначить детали `black` и `silver` соответствующим филаментам.
