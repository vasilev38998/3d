# Муравей Самоделка — flat-base v5

Исправленная версия без углублений под рельефом.

## Геометрия
- ширина: **160 мм**
- подложка: **2.00 мм**, полностью ровная по всей площади
- верхний рельеф: **1.00 мм**
- общая толщина: **3.00 мм**
- отверстия: **Ø4.2 мм**

Вся подложка печатается единым телом от Z=0 до Z=2.00 мм. Рамка, муравей, надписи и кольца отверстий начинаются только на плоскости Z=2.00 мм. Никаких декоративных элементов, утопленных в подложку, больше нет.

## Рекомендуемые файлы
- `muravey_samodelka_badge_v5_flatbase.stl` — основной цельный STL.
- `muravey_samodelka_badge_v5_flatbase_layerchange.3mf` — один цельный объект для Bambu Studio.

Для двух цветов используйте **смену филамента по слою на Z=2.00 мм**. Не импортируйте black/silver как «один объект с несколькими частями», если нужна идеально ровная верхняя плоскость подложки.

Отдельные `v5_black.stl` и `v5_silver.stl` оставлены как вспомогательные детали.

Для сопла 0.4 мм рекомендуется Arachne и слой 0.16–0.20 мм. Для максимально ровной и жёсткой тонкой основы можно поставить 100% заполнение.
