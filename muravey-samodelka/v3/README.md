# Муравей Самоделка — шильдик v3

Версия построена по финальному рендеру. Габариты готовой модели: **160 × 38.504 × 3.2 мм**.

Файлы после сборки:
- `muravey_samodelka_badge_v3_160mm.stl` — цельная модель для обычной печати.
- `muravey_samodelka_badge_v3_silver.stl` + `muravey_samodelka_badge_v3_black.stl` — двухцветная сборка под Bambu Studio / AMS.
- `muravey_v3.scad`, `outline_v3.svg`, `details_v3.svg` — исходники.

Параметры: отверстия 4.2 мм, серебристая основа до 2.0 мм, черная вставка 0.4 мм, рельеф 0.8 мм.

Для вида как на референсе назначьте серебристый/серый пластик детали `silver`, черный пластик детали `black`.
